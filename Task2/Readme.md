### Задание 2

Подход Domain-Driven Design (DDD):
Каждый бизнес разрабатывает свои системы самостоятельно. 
Базы данных для каждой системы оптимизируют под конкретные задачи и нагрузку. 
Это помогает улучшить производительность и эффективность всей системы.

Гибкость интеграции:
Новые бизнес-направления подключаются через интеграционную шину с помощью брокера сообщений Kafka. 
Это позволяет добавлять их без воздействия на остальные домены.

Преимущества:
 - Безопасность. Персональные данные, содержащиеся в мед.картах, строго изолированы в соответствии с требованиями ФЗ-152.
 - Скорость разработки. Домены эволюционируют автономно.
 - Производительность. Оптимизация и минимизации бизнес-логики в DWH.
