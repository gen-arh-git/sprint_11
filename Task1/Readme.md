## Проблемные места

 - DWH на MS SQL 2008. Завершена поддержка. Большие объемы данных. Снижение производительности и проблемы с масштабированием.
 - Power BI. Завершена поддержка. Интеграция с современными сервисами вызывает сложности.
 - Power Builder. Сложности в поддержке новых сервисов. Низкое внедрение бизнес-требований.
 - Шина на базе Apache Camel. Интеграция с современными сервисами вызывает сложности и ограничения с масштабированием.
 - В рамках существующей информационной архитектуры не предусмотрены стандарты, регламентирующие процессы обработки персональных данных.
